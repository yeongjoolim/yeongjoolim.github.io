# 大学准教授プロフィールサイト（多言語対応・明るいデザイン）

大学准教授向けの学術的なプロフィールWebサイトです。研究内容、業績、教育活動、メディア取材などを紹介するための洗練されたデザインのシングルページサイトで、**日本語・英語・韓国語の3言語に対応**しています。

## 🎯 プロジェクト概要

このサイトは、大学准教授の方が自身の研究活動や教育活動を効果的にアピールするためのプロフェッショナルなプロフィールサイトです。明るく親しみやすいカラーテーマを採用し、レスポンシブデザインにより、デスクトップ、タブレット、スマートフォンなど、あらゆるデバイスで美しく表示されます。

## 🔧 カスタマイズ方法

### 1. 多言語コンテンツの編集

`js/translations.json` ファイルを編集して、各言語のコンテンツをカスタマイズできます：

```json
{
  "ja": {
    "nav": {
      "brand": "Dr. 山田太郎"  // ← ここを編集
    }
  },
  "en": {
    "nav": {
      "brand": "Dr. Taro Yamada"  // ← ここを編集
    }
  },
  "ko": {
    "nav": {
      "brand": "Dr. 야마다 타로"  // ← ここを編集
    }
  }
}
```

翻訳ファイルの構造：
- `nav`: ナビゲーションメニュー
- `hero`: ヒーローセクション（名前、専門分野、所属）
- `about`: プロフィールセクション
- `research`: 研究内容
- `publications`: 業績
- `teaching`: 教育活動
- `media`: 取材・メディア掲載（新規追加）
- `contact`: 連絡先
- `timeline`: 学歴・職歴
- `courses`: 担当講義

### 2. 基本情報の変更

`js/translations.json` の以下の部分を編集してください：

- 各言語の `hero.title`: 氏名に置き換え
- 各言語の `hero.field`: 専門分野に置き換え
- 各言語の `hero.department`: 所属学部・学科名に置き換え
- その他のセクションも同様に編集

### 3. プロフィール画像の追加

`hero` セクションの `.profile-placeholder` を以下のように変更：

```html
<div class="hero-image">
    <img src="images/profile.jpg" alt="プロフィール写真" style="width: 200px; height: 200px; border-radius: 50%; object-fit: cover; border: 5px solid rgba(255, 255, 255, 0.3);">
</div>
```

### 4. 学歴・職歴の編集

`js/translations.json` の `timeline` セクションを各言語ごとに編集してください。

### 5. 研究内容のカスタマイズ

- `js/translations.json` の `research` セクションを編集
- 研究分野の説明を各言語で記載
- アイコンは `index.html` で変更可能（[Font Awesome](https://fontawesome.com/icons)から選択）
- キーワードを各言語で追加・編集

### 6. 業績リストの更新

- `index.html` 内の論文、学会発表、著書のリスト（`.publication-list li`）を編集
- 各言語版のサイトで同じ内容を表示するため、多言語化は不要（論文タイトルなどは原語のまま）
- 必要に応じて各言語で別々の業績リストを作成可能

### 7. 担当講義の編集

`js/translations.json` の `courses` と `teaching` セクションを編集して講義情報を更新

### 8. 連絡先情報の変更

- `js/translations.json` の `contact` セクションを各言語で編集
- メールアドレスや電話番号は `index.html` で直接編集
- ソーシャルメディアリンクのURLを `index.html` で更新

### 9. カラーテーマの変更

`css/style.css` の `:root` セクションで色を変更：

```css
:root {
    --primary-color: #4a90e2;    /* プライマリカラー（明るいブルー） */
    --secondary-color: #50c878;  /* セカンダリカラー（明るいグリーン） */
    --accent-color: #ff6b9d;     /* アクセントカラー（ピンク） */
}
```

### 10. デフォルト言語の変更

`js/main.js` の以下の行を編集：

```javascript
let currentLang = 'ja'; // 'ja', 'en', 'ko' のいずれかに変更
```

## 🌍 多言語機能の詳細

### 言語切り替えの仕組み

1. **自動保存**: ユーザーが選択した言語設定はブラウザのlocalStorageに保存され、次回訪問時に自動的に適用されます
2. **リアルタイム切り替え**: ページをリロードせずに瞬時に言語が切り替わります
3. **完全対応**: すべてのセクション、フォームメッセージ、日付表示が選択言語に対応

### 新しい言語の追加方法

`js/translations.json` に新しい言語を追加できます：

```json
{
  "ja": { ... },
  "en": { ... },
  "ko": { ... },
  "zh": {  // 中国語を追加する例
    "nav": {
      "brand": "Dr. [姓名]",
      ...
    }
  }
}
```

HTML側にも言語ボタンを追加：

```html
<button class="lang-btn" data-lang="zh">中文</button>
```
